These sensor entities will be available to the diary prompt. Configure them in the HA Sensors tab.

How it works

Reachy pulls sensor history from Home Assistant once per day, when the diary is generated. Selected entities (weather, room temperature, motion sensors, etc.) become context for the LLM — the diary prompt decides how to weave them in.
  1. Paste your HA URL + a long-lived access token below.
    In HA: Profile → Security → Long-Lived Access Tokens → Create Token.
  2. Click Test Connection to verify.
  3. Click Refresh List, check the entities you want Reachy to know about, then Save Selection.
  4. That's it — they show up in tonight's diary automatically.
